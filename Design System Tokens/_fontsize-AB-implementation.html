Font-size: Option A vs B — Figma vs Dev

Disposable. How each option is structured in Figma and how it ships in CSS.

Option A

Brand scale factor

In Figma
Breakpoints (Desktop·Tablet·Mobile) font-size/h1 32 · 28 · 24 font-size/body 16 · 16 · 15 font-size/caption 13 · 13 · 12 Core / Brand (SkillUp·BrandX) font-family Montserrat · Poppins build config (not a variable) font-scale 1.0 · 1.10
In Dev (CSS)
:root{
  --sk-font-scale: 1;
  --sk-font-h1: calc(2rem * var(--sk-font-scale));
  --sk-font-body: calc(1rem * var(--sk-font-scale));
}
@media (max-width:640px){
  :root{ --sk-font-h1: calc(1.5rem * var(--sk-font-scale)); }
}
[data-brand=brandx]{ --sk-font-scale: 1.10; }  /* 1 line */
Figma renders BrandX at the same px as SkillUp — the factor applies only at build. Figma variables can't multiply, so brand optical sizing is not previewable. Uniform scaling only.

Option B

Chaining · explicit tokens

In Figma
Brand (SkillUp·BrandX) font/h1-desktop 32 · 40 font/h1-tablet 28 · 34 font/h1-mobile 24 · 28 font/body-desktop 16 · 16 …×each size font-family Montserrat · Poppins Breakpoints (routing) font-size/h1 → brand/font/h1-{bp}
In Dev (CSS)
:root{ --sk-font-h1: 2rem; }
@media (max-width:640px){ :root{ --sk-font-h1: 1.5rem; } }

[data-brand=brandx]{ --sk-font-h1: 2.5rem; }        /* 40 */
@media (max-width:640px){
  [data-brand=brandx]{ --sk-font-h1: 1.75rem; }     /* 28 */
}
/* repeated per size × breakpoint */
Figma renders the real BrandX sizes (actual variables). Full per-size control. Cost: many tokens and verbose, repeated CSS overrides.

Decisive difference is design-time: with A the Figma file cannot preview a brand's optical sizing (variables can't multiply), so you see canonical SkillUp px with only the font swapped. B shows true sizes in Figma at the cost of a token per size per breakpoint per brand.
