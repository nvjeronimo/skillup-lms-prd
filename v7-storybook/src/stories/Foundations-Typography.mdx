# Typography

Three-font system. Strict tier rules — don't cross them.

## The three faces

**Montserrat** — UI workhorse. Use for everything ≤ 24px. Weights 400 / 500 / 600.

**Playfair Display** — display moments only. Use for ≥ 28px (quiz titles, results, hero text). Weights 600 / 700. Always with `letter-spacing: -0.01em` to tighten the tracking.

**Outfit** — small-caps label tier. Use for eyebrows, MODULE labels, timestamps, counters, tabular numerics. Replaces JetBrains Mono from v5 — Outfit is shorter, friendlier, and contrasts cleanly with Montserrat without feeling brutalist.

## Tabular figures

Numeric label contexts use Outfit's OpenType `tabular-nums` so digits stay aligned as values change (timestamps tick, counters increment, scores update). Add `font-variant-numeric: tabular-nums` or the `.num-tabular` utility class.

## Don't do this

- ❌ Inter (was used in earlier mocks; deprecated in v6).
- ❌ Playfair under 28px.
- ❌ Montserrat for tabular timestamps (use Outfit).
- ❌ All-caps Montserrat for eyebrows (use Outfit).
