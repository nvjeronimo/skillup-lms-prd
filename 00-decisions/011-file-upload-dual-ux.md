> Product decision locked during discovery. Push back NOW if you disagree — mid-build reversal is 10x more expensive.

**Decision** — File upload supports both drag-and-drop and the file picker.

**Why**
- "Don't force a single interaction pattern." — different learners and devices favour different affordances.

**Source** — Figma `3832-18102` "Key Decisions" + BA exec summary, 2026-06-08. [`../LMS-HANDOFF/BA/01-executive-summary.md`](../LMS-HANDOFF/BA/01-executive-summary.md).

**edX basis** — n/a.

**Design** — LMS ICP Phase 1 · Peer-graded Assignment screen (file upload), node-id unknown.

**Dev impact** — File upload molecule (drag-drop zone + picker button).

**Alternatives rejected** — Picker-only or drag-drop-only: rejected — forces one interaction pattern on all users.
